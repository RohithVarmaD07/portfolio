# Portfolio design brief



Status: local draft implemented and inspected on November 1, 2026; publication pending.



## Engineering in View



Warm paper, deep green ink, restrained gold, architectural rules and generous spacing establish an editorial identity. Georgia, Segoe UI and system monospace fonts avoid downloads and licensing ambiguity from external assets. The design uses original CSS shapes and typography rather than stock imagery.



The visitor moves from professional focus to MediFlow's engineering decisions, recorded evidence and limitations, then Agentic DataOps plans, skills and approved local profile information. Five keyboard-operable architecture buttons have an accompanying text explanation. Four synthetic recorded scenarios are selectable and resettable; they are not live computation. Native disclosure controls expose deeper decisions without hiding the main story.



## Technical choice



Use authored HTML, CSS and browser JavaScript in `dist/`, with built-in Node scripts for checks and loopback preview. This supersedes the proposed Astro stack for the initial release: the current design needs no framework, package install or production server. No sibling imports, backend, cloud connection, model call or remote font is required.



## Accessibility and performance



Semantic headings, skip navigation, focus outlines, reduced-motion CSS and responsive layouts are implemented. Browser checks found no horizontal overflow at 320, 361, 768 and 1440 pixels. All architecture controls responded to Enter. Selected text contrast pairs exceed 4.5:1. These are limited checks, not a complete accessibility certification.



No Lighthouse, screen-reader audit, zoom audit, cross-browser matrix or controlled load-time benchmark has run. Static asset bytes are recorded in the verification report; a small payload is not a measured performance score.



## Publication boundary



Name and title are approved only for local use. No fake project URLs, testimonials, employer results or cloud execution claims. MediFlow uses synthetic records. Resume-reported skills are distinguished from project-verified skills. The target launch date remains conditional on content, privacy, repository and hosting approval.
